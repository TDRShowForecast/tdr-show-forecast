## 実行ファイル

ソースは tdr-bot-source.zip。展開後の docs/simple.md が最新手順です。

- 起動：python -m tdrbot.simple run
- 実測の確認：python -m tdrbot.simple weather
- 停止／再開：python -m tdrbot.simple pause / resume
- コンテナ：Dockerfile.simple / compose.simple.yaml

実行先を1か所にし、stateを永続化します。Xの秘密情報は実行先の秘密設定のみへ保存します。.env.simpleを公開しないでください。
