# TDRショーパレ予測Bot（非公式）

X: @TDRShowForecast。スマホから管理するためのクラウド構成です。
**X投稿と定期実行はまだ無効です。**

## 設定済み

- GitHub Actionsの手動実行
- Supabase Free（東京）のPostgreSQL接続とBot用の非公開スキーマ
- 公演・気象・予測・結果・投稿・障害履歴のテーブル
- 111件の自動テスト
- 一時的な通信失敗時の1回の再試行（アクセス拒否は再試行しません）

ソースは `tdr-bot-source.zip` にあります。ワークフローが展開して実行します。秘密情報はGitHub Secretsだけに登録してください。

## スマホから手動実行

Actions → TDR Forecast Bot → Run workflow から選びます。

| operation | 内容 |
|---|---|
| diagnose | 気象通信診断。DATABASE_URLがあれば当日の公式予定・気象・判定保留を含む予測の保存検証も実行。Xには投稿しません |
| test | 外部通信・投稿を行わない自動テスト |
| run | 公演取得と監視時刻に応じた予測を1回実行 |
| status | DB内の運用状態を確認 |
| pause / resume | 投稿停止 / 解除。初回投稿承認などのガードは解除しません |

## 未完了

クラウドでの公演取得は通信タイムアウトの検証中です。正常取得した公式robots.txtを日時・ハッシュ付きで保存し、通常24時間以内に更新します。通信障害時のみ最大7日まで保存済みポリシーを使い、期限切れ・HTTP拒否時は取得を停止します。公演時刻のキャッシュ期限とは独立です。基本の風・雨・気温・湿度は取得できましたが、雷・地点の雨雲・有効なWBGT情報が不足しています。数値は無理に生成せず判定保留にします。公演ごとの屋外区分・適用モデルが未検証の場合も保留です。

X認証情報4件、料金・利用条件の確認、初回投稿承認、通知先の登録が残っています。定期稼働は `CLOUD_ENABLED=true`、投稿は `LIVE_POSTING=true` と `INITIAL_POST_APPROVED=true` が必要です。動作・料金を確認するまで有効化しません。

## 運用上の制限

無料クラウドは定刻実行や長期無人稼働を保証しません。GitHubの予約実行やSupabase無料枠には停止・遅延の制限があります。Xの利用料は別です。予測モデルは依頼者の経験に基づく未検証の仮説で、現在の公式運営基準ではありません。
