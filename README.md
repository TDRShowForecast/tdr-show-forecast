# TDRショーパレ予測Bot（非公式）

X: @TDRShowForecast。スマホから管理するためのクラウド構成です。
**X投稿と定期実行はまだ無効です。**

## 設定済み

- GitHub Actionsの手動実行
- Supabase Free（東京）のPostgreSQL接続とBot用の非公開スキーマ
- 公演・気象・予測・結果・投稿・障害履歴のテーブル
- 128件の自動テスト（2026年11月14日）
- 公式カレンダーをChromiumで表示し、見える公演カードの時刻を取得する処理
- 日付・パーク・URL・取得時刻の照合、取得不能時の判定保留

ソースは `tdr-bot-source.zip` にあります。ワークフローが展開して実行します。秘密情報はGitHub Secretsだけに登録してください。

## スマホから手動実行

Actions → TDR Forecast Bot → Run workflow から選びます。

| operation | 内容 |
|---|---|
| diagnose | 気象通信診断。DATABASE_URLがあれば当日の公式予定・気象・判定保留を含む予測の保存検証も実行。Xには投稿しません |
| test | 外部通信・投稿を行わない自動テスト |
| run | 公演取得と監視時刻に応じた予測を1回実行 |
| status | DB内の運用状態を確認 |
| pause / resume | 投稿停止 / 解除。初回投稿承認などのガードは解除しません |
